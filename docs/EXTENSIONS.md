## 已落地 ✅

### 1. AI 成本护栏（频控 + 每日预算上限）
| 项 | 值 |
|---|---|
| 价值 | **高**：群内 @刷屏会瞬时放大调用量，直接产生真实费用；护栏是最直接的止损手段 |
| 优先级 | **P0** |
| 难度 | **低**（约 30 行代码，无新依赖） |

**问题**：任何人反复 @机器人都会无限制触发 `/chat/completions`，无任何节流。

**改动位置**
- `src/config.js`：新增 `AI_RATE_LIMIT_ENABLED`、`AI_RATE_LIMIT_PER_MIN`、`AI_DAILY_LIMIT`
- `src/ai.js`：新增 `checkRateLimit(kv, scope, cfg)`（60 秒滑动窗口）、`checkDailyBudget(kv, cfg)`、`bumpBudget(kv)`
- `src/handlers.js`：AI 分支前串联两级护栏，超限返回友好提示而非静默

**验证方式**
- `npm test` → 「AI 正常回复并记住上下文」「每分钟频控拦截第 3 次」「每日预算上限拦截」3 项
- 手工：连发 `AI_RATE_LIMIT_PER_MIN+1` 条 → 收到「提问太频繁」提示

**回滚**：恢复 `src/handlers.js` 的 AI 分支（删除两段护栏判断）即可，不影响其他链路。

## 待确认（按建议排期）

### 2. 违规证据留存与申诉闭环
| 项 | 值 |
|---|---|
| 价值 | **中高**：误杀是广告过滤最大的运营成本；有证据 + 申诉才能真正降误杀 |
| 优先级 | **P1** |
| 难度 | **中** |

**现状**：`violations` 集合已落库（时间/群/成员/规则/命中/原文/处置），但无检索、导出与申诉状态。

**做法**：给 violation 增加 `appealStatus`（none/pending/approved/rejected）、`appealReason`；后台加申诉审核页；支持按时间范围导出 CSV。

---

### 3. 规则命中回放（防误杀）
| 项 | 值 |
|---|---|
| 价值 | **高**：改规则前先在历史消息上试跑，避免一改就误伤 |
| 优先级 | **P1** |
| 难度 | **中** |

**现状**：后台维护的关键词/正则**已对机器人实时生效**（`checkAd(text, cfg, dynamicRules)`）。

**做法**：后台提供「规则试跑」输入框，对最近 N 条历史消息跑一遍新规则，展示会命中的样本，确认后再启用。

---

### 4. 多群差异化策略模板
| 项 | 值 |
|---|---|
| 价值 | **中高**：不同群的尺度差异很大（亲友群 vs 交易群） |
| 优先级 | **P2** |
| 难度 | **中** |

**现状**：阈值/时长/开关是全局环境变量，所有群共用。

**做法**：把 `AD_MUTE_THRESHOLD` / `AD_MUTE_SECONDS` / system prompt 下沉为群级配置（存 KV），后台按群编辑；未配置的群回落到全局默认值。

**进展**：欢迎语/退群提示已完成下沉（2026-10-23）——全局默认在后台「欢迎词设置」，群级覆盖在「群管理」编辑弹窗的「专属欢迎词 / 专属退群提示」字段，取值优先级：群级 > 全局设置 > 环境变量 > 内置默认。阈值/时长/system prompt 仍为全局。

---

### 5. 可观测性增强
| 项 | 值 |
|---|---|
| 价值 | **中**：边缘函数日志分散，出问题时定位慢 |
| 优先级 | **P2** |
| 难度 | **低中** |

**做法**：统一结构化日志（JSON，带 `ts/level/action/group/user/msgId`）；后台日志页增加按时间/动作/操作人筛选与分页；关键错误（AI 失败、撤回失败、验签失败）计数进概览。
