# 群规说明（机器人自动执行版）

> 面向群成员的群公告文案，内容与机器人当前真实行为一一对应。
> 处罚参数如有调整（后台「群设置」），请同步更新本文件第 3 节。

## 可直接复制的群公告文案

📋═══════════════════════📋
　　　本 群 群 规
　（由群机器人自动执行）
📋═══════════════════════📋

【一、机器人能做什么】
👋 新成员进群 → 自动发送欢迎语
🛡️ 广告过滤 → 自动识别违规内容并处罚
🚪 入群申请 → 通知管理员审批，黑名单用户自动拒绝
🤖 AI 闲聊 → 当前已关闭，机器人不参与聊天，只负责管群

【二、禁止发布的内容（自动识别）】
1️⃣ 任何链接 / 网址（http、www 开头等）
2️⃣ 引流联系方式：「加我 vx / 微信 / QQ」等
3️⃣ 营销广告：刷单、兼职、免费领取、扫码领红包、低价代刷、代理加盟等
4️⃣ 拉群引流：群号、邀请码、邀请链接
5️⃣ 刷屏：同一字符连续发送 10 次以上

【三、违规处罚（次数自动累计）】
▪ 第 1 次：⚠️ 警告 + 撤回消息 + 禁言 10 分钟
▪ 第 2 次：禁言 20 分钟
▪ 第 3 次：禁言 40 分钟
▪ 第 4 次：🚫 移出群聊并加入黑名单，无法再次申请入群

【四、注意事项】
· 自己删掉违规消息没用——处罚在发送时已生效，次数照算
· 群管理员发布的内容不受过滤限制；被误判请联系管理员处理
· 管理员指令以 / 开头（如 /管理），仅管理员可用，普通成员发送无效

【五、本群欢迎你】
文明发言，互相帮助，祝玩得愉快 🎉

## 文案与机器人行为的对照表（维护用，不发群）

| 群规条目 | 机器人实际行为 | 代码/配置出处 |
|---|---|---|
| 链接 / 网址 | 内置规则 `url` + `tencent-link` 正则命中 | `src/adfilter.js` BUILTIN |
| 引流联系方式 | 内置规则 `contact`（加 v/微信/QQ + 号码） | 同上 |
| 营销广告 | 内置规则 `money-bait` 关键词组 | 同上 |
| 拉群引流 | 内置规则 `invite`（群号/邀请码） | 同上 |
| 刷屏 | 内置规则 `flood`（同字符 ≥10 连发） | 同上 |
| 处罚阶梯 | 1/2/3 次禁言 10/20/40 分钟，第 4 次踢出+拉黑 | env `AD_MUTE_THRESHOLD=1`、`AD_MUTE_SECONDS=600`（翻倍）、`AD_KICK_THRESHOLD=4` |
| 自己删消息没用 | 违规计数在命中时落库，撤回由机器人执行 | `src/handlers.js` handleAdViolation |
| 管理员豁免 | 管理员消息跳过广告过滤 | 广告分支 isAdmin 判断 |
| AI 已关闭 | 后台「群设置 → AI 对话」总开关 aiChatEnabled=false | settings 集合 |
| 入群申请审批 | 默认人工审批（自动通过已关）；黑名单自动拒绝并拉黑 | joinAutoApprove=false、joinAutoRejectBlacklist=true |
| 黑名单无法入群 | 平台群黑名单 + 机器人本地黑名单双保险 | approveJoinRequest / GROUP_JOIN_REQUEST 分支 |

## 调整群规时需要改哪里

- **处罚力度/阶梯**：后台「群设置 → 违规处置」（留空回退环境变量）
- **违规类型**：后台「过滤规则」加自定义关键词/正则；内置 6 条改 `src/adfilter.js`
- **欢迎语/退群提示**：后台「群设置 → 迎宾送别」，或「群管理」里按群覆盖
- **AI 开关**：后台「群设置 → AI 对话」（当前：关闭）
